# ПР6. Анімація, файли, медіа, PDF, тестування, ресурси, реліз — варіант 2
**«Вітрова електростанція з моніторингом швидкості вітру»**
Виконав: Гаврилюк Михайло Євгенійович, ТВ-31

Android Studio → File → Open → ця тека → Sync → Run (варіант `fullDebug`, JDK 21).
Юніт-тести: `app/src/test`; UI-тести: `app/src/androidTest`; реліз — див. [RELEASE.md](RELEASE.md).

| Заняття | Що реалізовано |
|---|---|
| 21. Анімація | animateFloatAsState / animateColorAsState, AnimatedContent (старе → нове значення), нескінченне обертання роторів, Crossfade, updateTransition для синхронних анімацій дашборда, AnimatedVisibility, animateContentSize; домашнє — шкала виробітку з тенденцією і деталями за дотиком |
| 22. CSV і JSON | CSV за RFC 4180 (лапки, коми), kotlinx.serialization, атомарний запис у filesDir, пропуск пошкоджених рядків з поясненням; аналітика за періодом і типом станції з графіками; домашнє — журнал у CSV + JSON із сортуванням |
| 23. Фото й документи | Photo Picker і SAF без дозволів, зменшення фото до 1600 px з EXIF-поворотом, мініатюри з кешем (LruCache + диск), перегляд PDF через PdfRenderer, DOCX через FileProvider, перевірка типу за сигнатурою, перейменування, сортування й фільтр |
| 24. PDF-звіти | PdfDocument: таблиці з переносом сторінок, графіки, кругова діаграма, стилі; багатосторінковий звіт із розділами та параметрами від користувача; асинхронна генерація з прогресом; попередній перегляд і надсилання |
| 25. Тестування | юніт-тести (крайні випадки, віртуальний час для повторів і тайм-аутів), UI-тести Compose з testTag і FakeRepository, навігація, покриття коду |
| 26. Ресурси й теми | CPU (системний або процесу), RAM, heap, батарея, сховище, мережа у фоновому потоці; кільцеві та сегментні індикатори; світла / темна / системна тема зі збереженням; навантаження CPU кількома потоками |
| 27. Реліз | підпис через keystore.properties, R8 + shrinkResources, варіанти demo / full, перевірка готовності до релізу в застосунку, метадані Google Play, презентація |
