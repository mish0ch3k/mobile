# ПР1. Розробка ПЗ мобільних пристроїв — варіант 2
**«Вітрова електростанція з моніторингом швидкості вітру»**
Виконав: Гаврилюк Михайло Євгенійович, ТВ-31

## Запуск
Android Studio (Ladybug або новіша) → File → Open → ця тека → Sync → Run.
Unit-тести: `app/src/test` → Run.

## Структура
- `logic/WindPowerCalculator.kt` — P = ½·ρ·A·v³·Cp, характеристика турбіни (3 / 12 / 25 м/с), шкала Бофорта
- `logic/AuthValidator.kt` — валідація логіну, пароля, e-mail, демо-авторизація
- `s1` … `s4` — екрани практичних занять 1–4 (домашнє + базовий / середній / просунутий рівні)
- `composables/DisplayModeSelector.kt` — перемикач заняття та рівня

Демо-вхід (заняття 4): `operator` / `wind2026`
