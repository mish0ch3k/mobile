# ПР4. Flow, списки, фільтрація, мапи і GPS — варіант 2
**«Вітрова електростанція з моніторингом швидкості вітру»**
Виконав: Гаврилюк Михайло Євгенійович, ТВ-31

Android Studio → File → Open → ця тека → Sync → Run (JDK 21). Модульні тести: `app/src/test`.
Для мап потрібен інтернет (плитки OpenStreetMap). Для геолокації в емуляторі: «⋮ → Location» → задати точку (наприклад, Одеса) → Set location.

| Заняття | Що реалізовано |
|---|---|
| 13. Flow і корутини | холодний потік датчика; filter / map / catch / onCompletion; debounce порогу тривоги; гарячий SharedFlow з кількома підписниками; zip двох анемометрів, combine датчика з прогнозною моделлю; retryWhen; моніторинг станції (merge трьох турбін, контроль відсутності даних) |
| 14. LazyColumn і мапи | список об'єктів; картки з переходом до деталей (Navigation); двобічний зв'язок списку з мапою OpenStreetMap; фільтр і сортування карток, порожній стан |
| 15. Фільтрація, сортування, пошук | пошук за кількома словами; фільтри за типом, статусом, регіоном, діапазоном потужності; сортування за основним і додатковим ключем; вибір кількох об'єктів з підсумком |
| 16. GPS і мапи | позиція через LocationManager (callbackFlow), запит дозволів, InfoWindow маркерів, синхронізація зі списком, сортування за відстанню, найближча ВЕС |

Мапа — osmdroid (OpenStreetMap): працює без ключа API, на відміну від Google Maps SDK.
Дані об'єктів — імітаційне джерело з оновленням телеметрії кожні 4 с.
