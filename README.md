# Вітрова електростанція з моніторингом швидкості вітру

Практичні роботи та РГР з дисципліни «Розробка програмного забезпечення мобільних пристроїв», варіант 2.
Виконав: Гаврилюк Михайло Євгенійович, ТВ-31, КПІ ім. Ігоря Сікорського.

| Тека | Робота | Заняття |
|---|---|---|
| [PR01_WindFarm](PR01_WindFarm) | ПР1. Kotlin, Compose, базовий UI | 1–4 |
| [PR02_WindFarm](PR02_WindFarm) | ПР2. Навігація, стан, MVVM, збереження даних | 5–8 |
| [PR03_WindFarm](PR03_WindFarm) | ПР3. Repository, REST API, автентифікація, обробка помилок | 9–12 |
| [PR04_WindFarm](PR04_WindFarm) | ПР4. Flow, списки, фільтрація, мапи і GPS | 13–16 |
| [PR05_WindFarm](PR05_WindFarm) | ПР5. Сенсори, сповіщення, графіки, кастомні компоненти | 17–20 |
| [PR06_WindFarm](PR06_WindFarm) | ПР6. Анімація, файли, PDF, тестування, ресурси, реліз | 21–27 |
| [RGR_WindFarm](RGR_WindFarm) | РГР. Мобільний застосунок моніторингу ВЕС | — |

Кожна тека — окремий проєкт Android Studio (Kotlin 2.0, Jetpack Compose, Material 3, JDK 21).
Відкрити: Android Studio → File → Open → тека проєкту → Sync → Run. Опис кожної роботи — у README.md теки.
