# РГР. Мобільний застосунок «Вітрова електростанція з моніторингом швидкості вітру» (варіант 2)
Виконав: Гаврилюк Михайло Євгенійович, ТВ-31

Android Studio → File → Open → ця тека → Sync → Run (JDK 21). Модульні тести: `app/src/test` (JUnit, kotlinx-coroutines-test).

**Технології:** Kotlin 2.0, Jetpack Compose + Material 3, MVVM (ViewModel + StateFlow), Room (Entity / DAO / Database, SQL-агрегація), Retrofit + Gson (REST API Open-Meteo), Navigation Compose, Kotlin Flow, WorkManager, Version Catalog. minSdk 24, targetSdk 34.

| № | Завдання варіанту | Екран | Реалізація |
|---|---|---|---|
| 1 | Моніторинг швидкості вітру й потужності в реальному часі | Моніторинг | телеметрія кожні 10 с → Room → Flow → StateFlow; шкала вітру з робочими зонами турбіни, навантаження станції, графіки |
| 2 | Розрахунок потужності турбіни та станції | Розрахунок | P = ½·ρ·A·v³·Cp, ρ = p/(R·T), перерахунок вітру на висоту маточини, межа Бетца, крива потужності |
| 3 | Прогноз вітру та виробітку | Прогноз | Retrofit → Open-Meteo (вітер на 100 м, 3 доби), кеш у Room з TTL 1 год, офлайн-режим, прогноз МВт·год по годинах і добах |
| 4 | Журнал вимірів і аналітика вітрового ресурсу | Аналітика | SQL GROUP BY по добах, фільтри, гістограма, параметри розподілу Вейбулла, оцінка річного виробітку |
| 5 | Тривоги та сповіщення про небезпечні умови | Тривоги | правила (шторм, пориви, обмерзання, знижений виробіток, несправність датчика, вікно ТО), журнал у Room, сповіщення, фонова перевірка прогнозу WorkManager |

Структура: `domain` — фізика, статистика, прогноз, правила тривог (без Android); `data` — Room, Retrofit, репозиторії; `telemetry` — збирач телеметрії; `notify` — сповіщення й фонова робота; `ui` — ViewModel і екрани Compose.
