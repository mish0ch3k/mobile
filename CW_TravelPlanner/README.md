# Планувальник подорожей (Travel Planner)

Курсова робота з дисципліни «Розробка програмного забезпечення мобільних пристроїв».
Тема 4: «Додаток, який допомагає користувачам планувати свої подорожі».
Виконав: Гаврилюк Михайло Євгенійович, ТВ-31. Керівник: Недашківський О. Л.

## Можливості
- Подорожі: створення, редагування, видалення; пошук і фільтр (майбутні / тривають / завершені).
- Пошук міста з координатами (Open-Meteo Geocoding API).
- Маршрут по днях: активності з часом, тривалістю, місцем, вартістю, категорією; позначка «виконано»;
  виявлення накладок у розкладі; вільний час кожного дня.
- Нагадування за годину до активності (WorkManager + сповіщення).
- Бюджет: витрати в різних валютах з конвертацією (open.er-api.com, кеш у Room, офлайн-курси),
  розподіл за категоріями, стан бюджету, ліміт на день, частка на людину.
- Список речей: рекомендації за типом подорожі, тривалістю й прогнозом погоди, власні речі, прогрес збору.
- Погода на 16 днів для пункту призначення (Open-Meteo Forecast API) з виділенням днів подорожі.
- Мапа маршруту (OpenStreetMap, osmdroid) з маркерами активностей і лінією маршруту.
- «Поділитися» планом подорожі текстом.

## Технології
Kotlin 2.0, Jetpack Compose (Material 3), MVVM (ViewModel + StateFlow), Room, Retrofit + Gson,
Navigation Compose, WorkManager, osmdroid, JUnit 4. minSdk 26, targetSdk 34.

## Запуск
Android Studio → File → Open → ця тека → Sync → Run (JDK 21).
Модульні тести: `app/src/test` (29 тестів, номери TC-01…TC-29 відповідають тест-кейсам записки).

## Структура
```
app/src/main/java/ua/kpi/travel/
  domain/   моделі та бізнес-логіка (валідація, маршрут, бюджет, речі, звіт)
  data/     Room (local), Retrofit (remote), репозиторії
  notify/   нагадування (WorkManager)
  ui/       ViewModel, екрани Compose, тема
```
