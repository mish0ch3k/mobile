# ПР5. Сенсори, сповіщення, графіки, кастомні компоненти — варіант 2
**«Вітрова електростанція з моніторингом швидкості вітру»**
Виконав: Гаврилюк Михайло Євгенійович, ТВ-31

Android Studio → File → Open → ця тека → Sync → Run (JDK 21). Модульні тести: `app/src/test`.
В емуляторі значення сенсорів задаються в «⋮ → Extended controls → Virtual sensors» (вкладки Device Pose та Environment: тиск, температура, вологість).

| Заняття | Що реалізовано |
|---|---|
| 17. Сенсори | SensorManager → callbackFlow → StateFlow; перевірка показів на коректність; базовий — акселерометр (значення, графік, таблиця); середній — 4 сенсори в картках з міні-графіками; просунутий — панель з вибором сенсорів, порогами, журналом із фільтрами та сортуванням; домашнє — барометр + термометр + гігрометр → густина повітря → потужність турбіни, ризик обмерзання |
| 18. Локальні сповіщення | канали (NotificationChannel) з різною важливістю; дозвіл POST_NOTIFICATIONS; сповіщення за кнопкою й після таймера; планування через WorkManager; фільтр журналу за категоріями; інтерактивні дії «Підтвердити / Відкласти / Деталі» з синхронізацією з UI; події від сенсорів (вібрація, падіння тиску, мороз) |
| 19. Графіки | власний графік на Canvas: лінія, стовпчики, комбінований; осі з «круглими» поділками; підказки при натисканні; масштаб жестом і кнопками, прокрутка; інтервали доба / 3 доби / тиждень; сума, середнє, пік; оновлення через StateFlow |
| 20. Кастомні компоненти | рівень-«бульбашка» (нахил), кругова шкала з анімованою стрілкою та зонами, компас (акселерометр + магнітометр), вектори гіроскопа та гравітації з налаштуванням кольору й масштабу; домашнє — модель турбіни (вид згори), керована телефоном |

Пакети: `sensors` — доступ до сенсорів і математика (ФНЧ, нахил, азимут, густина повітря), `notify` — канали, сповіщення, WorkManager, обробник дій, `charts` — дані й масштабування графіків, `s17…s20` — екрани занять.
